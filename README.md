# Bitrix CRM Dashboard

Статический MVP дашборда для CSV-выгрузок Битрикс24. Приложение работает без backend: данные, импорты, связи и журнал изменений хранятся в IndexedDB текущего браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`.

## Сборка для GitHub Pages

```bash
npm run build
```

Готовый статический сайт будет в папке `dist`. В `vite.config.ts` уже указан `base: "./"`, поэтому сборку можно публиковать как GitHub Pages artifact.

## Как пользоваться

1. Загрузите CSV лидов.
2. Загрузите CSV сделок.
3. Проверьте вкладки `Дашборд`, `Сквозная`, `Записи`, `Изменения`.
4. На вкладке `Настройки` отредактируйте справочник стадий и экспортируйте резервную копию JSON при необходимости.

Сквозная аналитика считает только уверенные связи сделка -> лид по сильным сигналам: телефон, email, DKT-поля и roistat. Слабые и неоднозначные связи показываются отдельно.

## CSV прямо в GitHub

Если хотите хранить CSV прямо в репозитории, положите файлы сюда:

- `public/data/leads.csv`
- `public/data/deals.csv`

Потом в дашборде нажмите `Лиды из data` и `Сделки из data`.
